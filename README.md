# 演唱會票夾

收藏自己看過的演唱會：每張票可以放照片或 15 秒影片、附上現場錄音，並在世界地圖上看到自己去過哪些場館。

這是一個 **PWA（網頁 App）**，放在 GitHub Pages，不用上架 App Store／Google Play。

## 怎麼安裝到手機

| 手機 | 步驟 |
| --- | --- |
| iPhone | 用 **Safari** 打開網址 → 下方「分享」→「加入主畫面」 |
| Android | 用 **Chrome** 打開網址 → 跳出「安裝應用程式」，或右上角選單 →「加到主畫面」 |

加到主畫面後會有桌面圖示、全螢幕開啟，用起來就像一般 App。

## 功能

- **12 種票型**：6 種票券（經典圓角、撕線橫票、海報、復古入場券、拍立得、工作證）＋ 6 種郵票（齒孔、雙框題字、彩色齒邊、切角、側題、郵戳蓋銷）
- **自己調色**：畫布色、票色、字色，7 組預設配色
- **照片／影片票面**：票的比例跟著照片或影片（直拍＝直式票）；影片可在 App 內選 1～15 秒的片段
- **現場錄音**：匯入錄音檔或保留影片原音，點迴紋針播放；錄音也能在 App 內修剪
- **世界地圖**：滑動票卡，地圖飛到那個場館；黃色虛線依日期串起看過的場館
- **場館搜尋**：內建全球約 120 個主要演唱會場地，也可自行輸入或在地圖上點選位置
- **撕票根**：點 ADMIT ONE 撕下，票根顯示日期、時間、座位
- **全部票根**：票卡區往上拉，依年份瀏覽、批次刪除
- **編輯**：存好的票可以再換照片、改時間地點、換票型

## 資料與隱私

- 票、照片、影片、錄音 **只存在你自己手機的瀏覽器裡**（IndexedDB），不會上傳到任何伺服器
- 匯入照片時會重新繪製一次，**移除 GPS 位置與拍攝裝置資訊**
- 不使用廣告、不使用追蹤或分析工具
- 網頁設有內容安全政策（CSP），只允許連到地圖元件與字型的 CDN

> ⚠️ 從主畫面刪除 App 圖示、或清除瀏覽器網站資料，票會一起被刪掉。之後的版本會加入「備份匯出／匯入」。

## 專案結構

```
index.html              頁面骨架
manifest.webmanifest    PWA 設定（名稱、圖示、顏色）
sw.js                   離線快取
css/app.css             所有樣式
js/data.js              配色、場館清單、票型、範例票
js/store.js             本機資料庫（IndexedDB）與共用狀態
js/tickets.js           票面與背面的畫法
js/stage.js             主畫面：大字、座標、浮動票卡、往上拉
js/map.js               世界地圖（ECharts 4.9，從 CDN 載入）
js/ui.js                彈出大票、全部票根、新增／編輯、場館搜尋、修剪
js/app.js               錄音播放、刪除、按鈕事件、啟動
icons/                  App 圖示
```

不需要任何建置步驟，所有檔案直接就是網站。

## 在電腦上試跑

Service Worker 需要用網址開（不能直接雙擊 HTML）：

```bash
python3 -m http.server 8080
# 打開 http://localhost:8080
```

## 部署到 GitHub Pages

1. 到儲存庫的 **Settings → Pages**
2. **Build and deployment → Source** 選 **GitHub Actions**
3. 之後每次推到 `main`，`.github/workflows/pages.yml` 會自動部署
4. 網址是 `https://<你的帳號>.github.io/<儲存庫名稱>/`

更新程式時記得把 `sw.js` 裡的 `VERSION` 改掉，手機才會拿到新版。
